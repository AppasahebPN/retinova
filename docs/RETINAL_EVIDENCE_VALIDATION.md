## 1. Executive Summary & Policy Compliance

The NetraAI Retinal Evidence Subsystem extracts anatomical landmarks (Optic Disc, Fovea), retinal vessel architecture, and candidate lesion features (Microaneurysms, Haemorrhages, Hard Exudates, Soft Exudates) to provide clinical explainability alongside the frozen Swin V2 Tiny V1 screening model.

### 1.1 Strict Model Isolation
- **Frozen Swin V1**: Model architecture, checkpoint weights (`best_model.pt`), $512\times 512$ bicubic preprocessing, temperature scaling parameter ($T = 1.4555$), and optimal decision threshold ($\tau^* = 0.2993$) are **100% frozen**.
- **One-Way Dataflow**: Retinal evidence is an independent post-hoc explainability and clinical decision-support layer. It is **never** fed back into the Swin V1 classifier, preventing circular feedback or feature degradation.

### 1.2 Permanent Locked-Test-Set Policy
In strict compliance with independent clinical evaluation standards, all official IDRiD test partitions remain **permanently locked**:
1. **Part A Test Set**: 27 official test images — **LOCKED**
2. **Part B Test Set**: 103 official test images — **LOCKED**
3. **Part C Test Set**: 103 official test images — **LOCKED**

> [!IMPORTANT]
> Official IDRiD test sets were **never evaluated, tuned against, inspected, or accessed** during this development and validation cycle. They remain strictly reserved for future blind independent clinical trials.

## 3. Retinal Evidence Taxonomy: Supervised vs Heuristic

To maintain clinical integrity, all evidence generated by NetraAI is categorized explicitly:

| Evidence Component | Evidence Category | Ground Truth Available in IDRiD? | Clinical Designation |
| :--- | :--- | :--- | :--- |
| **Optic Disc (OD)** | Supervised / Annotation-based | Yes (Part A Pixel Masks + Part C Centroids) | Validated Landmark Localization & Mask |
| **Fovea** | Supervised / Annotation-based | Yes (Part C Coordinates) | Validated Center Coordinate ($E_{\text{norm}}$) |
| **Microaneurysms (MA)** | Supervised Evaluation | Yes (Part A Pixel Masks) | **Candidate Lesion Count** (Punctate dark) |
| **Haemorrhages (HE)** | Supervised Evaluation | Yes (Part A Pixel Masks) | **Candidate Lesion Count** (Blot/flame dark) |
| **Hard Exudates (EX)** | Supervised Evaluation | Yes (Part A Pixel Masks) | **Candidate Lesion Count** (Lipid deposits) |
| **Soft Exudates (SE)** | Supervised Evaluation | Yes (Part A Pixel Masks) | **Candidate Lesion Count** (Cotton-wool spots) |
| **Retinal Vessels** | **Heuristic / Morphological** | **NO** (No vessel pixel GT in IDRiD Part A) | Morphological vessel tree (unsupervised) |
| **Neovascularization (NV)**| **Unavailable** | **NO** (No pixel GT in IDRiD) | **Not validated / unavailable** |

> [!WARNING]
> **Zero Fabrication Policy**: Neovascularization (NV) masks are **never fabricated** or synthetically generated. NV is explicitly rendered as *"Not validated / unavailable"* in clinical summaries. All lesion outputs are denoted as **candidate lesion counts**, not confirmed clinical findings.

## 4. Pre-Defined Engineering Go/No-Go Acceptance Criteria

In adherence to scientific rigor, acceptance criteria were defined prior to reviewing validation results:

1. **Optic Disc Segmentation**: Mean Dice $\ge 0.60$, Mean IoU $\ge 0.45$, Centroid localization within anatomical nasal quadrant.
2. **Fovea Center Localization**: Mean Normalized Error $E_{\text{norm}} \le 1.0$ Optic Disc Diameters (standard clinical criterion for macular center localization: $E_{\text{norm}} = E_{\text{px}} / D_{\text{OD}}$).
3. **Sparse Lesions (MA, HE, EX, SE)**:
   - High Specificity ($\ge 0.98$) across non-lesion retinal pixels.
   - Object-level Lesion Recall $\ge 35\%$ on dominant micro-lesions (MA, EX).
   - False positive rate within clinically interpretable range (<50 candidates/image on average for macroscopic lesions).
4. **Retinal Vessels**: Qualitative vessel tree extraction without claiming supervised pixel accuracy.
5. **Frozen V1 Screening Invariance**: Calibrated probability variation $\le 10^{-5}$ on frozen benchmarks.

## 7. Clinical Explainability Language Standards

All clinical reports and user interface elements must adhere strictly to approved medical AI phraseology:

| DO USE | DO NOT USE | Clinical Rationale |
| :--- | :--- | :--- |
| *"Model attribution indicates regions driving AI recommendation"* | *"AI detected exact lesion"* | Prevents misrepresenting coarse attribution heatmaps as confirmed pathology. |
| *"Supporting candidate retinal evidence"* | *"Confirmed microaneurysms/hemorrhages"* | Candidates are morphological hypotheses for optometrist/ophthalmologist review. |
| *"Candidate lesion count: N"* | *"Confirmed lesion count: N"* | Avoids diagnostic over-claiming on uncurated candidates. |
| *"Validated landmark localization (OD / Fovea)"* | *"Perfect landmark boundary"* | Acknowledges pixel tolerance and anatomical variability. |
| *"Neovascularization: Not validated / unavailable"* | *"AI found no neovascularization"* | Clarifies that no validated NV detector was evaluated on IDRiD. |

## 8. Limitations & Clinical Disclaimers

1. **Vessel Segmentation**: IDRiD Part A contains no vessel ground truth masks. The vessel extraction module is heuristic morphology designed to prevent false positives at vessel bifurcations and should not be used as an authorized diagnostic vessel caliber measurement tool.
2. **Neovascularization**: Because IDRiD provides no pixel-level annotations for NV, Neovascularization is explicitly reported as unvalidated. Clinicians must perform biomicroscopic dilated fundus examination for NV detection.
3. **Class Imbalance & Sparse Lesions**: Microaneurysms represent fewer than $0.05\%$ of pixels in a high-resolution fundus image. Consequently, low pixel-level Dice does not imply failure of object-level sensitivity (45.2% object-level recall achieved on tiny punctate lesions).
4. **Central Macular Exudate Disruption**: In cases of extreme Diabetic Macular Edema with massive circinate exudates, hard exudate brightness can mimic optic disc reflectivity. The anatomical nasal boundary constraint mitigates this effect.
